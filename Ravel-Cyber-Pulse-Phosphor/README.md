# Ravel Cyber Pulse Phosphor

Flat FUI theme for Cinnamon with 1-px lines, corner brackets and subtle
scanlines. Includes the Cinnamon layer, GTK3, GTK4, libadwaita and Metacity
window borders.

Source, other variants and documentation:
https://github.com/ravelzh/ravel-cyber-pulse-cinnamon-theme

License: GPL-3.0. GTK and libadwaita parts are derived from Mint-Y-Dark
(Linux Mint, GPL-3.0).
