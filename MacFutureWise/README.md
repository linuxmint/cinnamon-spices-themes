# MacFutureWise

MacFutureWise is a Cinnamon desktop theme derived from **CBlue** by **Bundy01**.

It retains CBlue's translucent visual style while modifying the panel layout and
Grouped Window List appearance.

## Changes

- Compact panel spacing.
- Reduced extra padding around pinned applications.
- Open but unfocused applications use a green indicator.
- The focused application uses a white indicator with a translucent whitish highlight.
- Indicators appear above icons on top panels.
- Indicators appear below icons on bottom panels.
- Vertical panel orientations are also supported.
