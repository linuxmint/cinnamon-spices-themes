# Mint-Y-Noir

Built from an unmodified Linux Mint `Mint-Y-Dark` tree, so all credits go to the original creators.

Dark(er) neutral theme (no tint) based on Mint-Y-Dark, best suited for HDR monitors and tvs for which the Mint-Y-Dark is too bright. 

## What is included

Cinnamon, Metacity, GTK2, GTK3, GTK4 and libadwaita (1.5, 1.7 and 1.9) themes.

The theme is self-contained: it carries its own key theme, so it renders correctly even when it is the only theme installed on the machine.

## Requirements

The Mint-Y icon theme is recommended but not required — without it the window buttons fall back to the icon theme you have selected.
