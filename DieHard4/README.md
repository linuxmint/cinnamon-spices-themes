# DieHard4

By Nebulung.

A dark navy and burnt-orange theme for Cinnamon: flat, borderless controls,
and window frames with an orange stripe down the left edge, cut at 45
degrees at its foot.

## Includes

- Cinnamon: panel, menus, dialogs, notifications and OSDs
- GTK 3 and GTK 4 applications, and Cinnamon's window frames
- GTK 2 applications (needs the Murrine engine, `gtk2-engines-murrine`)
- Metacity and Marco window frames

## Using it

In System Settings, Themes: set **Applications** and **Desktop** to
DieHard4. The window frames follow the Applications theme. After
switching, restart Cinnamon (right-click the panel, Troubleshoot, Restart
Cinnamon) so the window frames update.

For the matching flat look elsewhere, Mint-Y icons with a dark panel suit
the theme well.
